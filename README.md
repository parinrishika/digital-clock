# Minimalist Digital Clock App

A sleek, real-time digital clock and date web application. It features a retro neon dashboard theme and automatically adapts to the user's local timezone.

## 🚀 Features
* **Real-Time Updates:** Updates time and seconds instantly using browser intervals.
* **12-Hour Format:** Automatically formats standard time with an AM/PM indicator.
* **Live Date Display:** Dynamically lists the full day, month, date, and year.

## 🛠️ Technologies Used
* **HTML5:** Basic structural semantic layout.
* **CSS3:** Custom neon typography and layout styling.
* **JavaScript (ES6):** Native Date objects and automated timing loops.
